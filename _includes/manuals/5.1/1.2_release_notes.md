## Release notes for {{page.version}}

### Headline features

#### Edit host parameters in bulk

On the All Hosts page, select multiple hosts and choose **Set parameters** to set a host-level override for a global parameter. Select the parameter and enter a value to apply. This action requires the `edit_hosts`, `view_params`, and `edit_params` permissions. Without `create_params`, hosts without an existing override are skipped.

#### OpenVox provisioning templates

The AutoYaST and FreeBSD provisioning templates now support the OpenVox agent.

#### HTTP proxy for Ubuntu autoinstall

Ubuntu autoinstall provisioning can now use an HTTP proxy. Set the `http-proxy` host parameter to the proxy hostname. If needed, set `http-proxy-port` to the port.

#### VM-specific SSH provisioning usernames

SSH provisioning now uses the username specified for a virtual machine when one is provided. If the virtual machine does not provide a username, Foreman uses the image username.

#### Keep existing network connections during Kickstart provisioning

Set the `network-no-activate` host parameter to `true` to prevent Kickstart from reactivating configured network interfaces. This can help when an existing bonded connection is needed during provisioning.

#### Parse URLs in templates

The `parse_url` template helper lets you extract components from a URL. For example, use it to obtain the hostname or fragment in a provisioning template.

### Upgrade warnings

#### Local PostgreSQL upgrades on Enterprise Linux 9

On Enterprise Linux 9, the installer upgrades eligible local PostgreSQL clusters to version 16. PostgreSQL 13 upgrades through version 15; PostgreSQL 15 upgrades directly to version 16. Plan downtime and verify your backup before upgrading.

Ensure that `/var/lib/pgsql` has free space equal to at least twice the current data directory size for PostgreSQL 13, or once its size for PostgreSQL 15. The installer does not upgrade remote databases.

#### Legacy Hammer SSH plugin

The installer no longer configures the legacy `hammer-cli-foreman-ssh` plugin. If you enabled it, review automation that uses `hammer host ssh` before upgrading. This change does not remove SSH or remote execution generally.

#### Hammer parameter output

In `hammer-cli-foreman` 5.1.0, the parameter output change also affects human-readable, JSON, and YAML output and can omit fields such as `is_property`. Review scripts that consume this output before upgrading.

#### Smart Proxy TLS cipher restrictions

Custom Smart Proxy cipher restrictions might not apply to every enabled TLS version. On Ruby/OpenSSL builds without `SSLContext#ciphersuites=`, `tls_ciphers` does not restrict TLS 1.3 ciphers. A cipher string valid for only one TLS version can also leave another enabled version unrestricted. Test the effective cipher configuration for each enabled TLS version.

### Deprecations

#### Foreman server on Debian 12 and Ubuntu 22.04

Running the Foreman server on Debian 12 (Bookworm) and Ubuntu 22.04 (Jammy) was deprecated in Foreman 5.0. Both remain supported in 5.1, but you should plan to move to a newer supported platform. This deprecation concerns the Foreman server, not clients.
