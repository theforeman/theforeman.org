## Release notes for {{page.version}}

This section will be updated prior to the next release.

### Headline features

#### PatternFly 5 UI updates
Continued migration to PatternFly 5 brings modernized notifications ([#38345](https://projects.theforeman.org/issues/38345)) and other UI components, improving the overall user experience with updated design patterns.

#### Multi-architecture iPXE support
iPXE chain UEFI now supports multiple architectures ([#38300](https://projects.theforeman.org/issues/38300)), enabling proper provisioning of ARM64 and other non-x86_64 servers by delivering the correct iPXE binary for each architecture.


### Upgrade warnings

#### Ruby 2.7 no longer supported
Ruby 2.7 support has been dropped ([#38115](https://projects.theforeman.org/issues/38115), [#38883](https://projects.theforeman.org/issues/38883)).

#### Grub1 removal
Support for legacy GRUB (Grub1) has been completely removed from both Foreman and Smart Proxy ([#38768](https://projects.theforeman.org/issues/38768), [#38772](https://projects.theforeman.org/issues/38772), [#38787](https://projects.theforeman.org/issues/38787), [#38791](https://projects.theforeman.org/issues/38791)). Only GRUB2 is supported going forward. If you are still using Grub1 for provisioning, migrate to GRUB2 before upgrading.
